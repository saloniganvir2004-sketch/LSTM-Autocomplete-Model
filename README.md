# LSTM-Based Smart Typing Autocomplete

## 📌 Project Overview

This project implements a next-word prediction system using LSTM (Long Short-Term Memory). It predicts the next word based on input text, similar to autocomplete systems.

## 🚀 Features

* Text preprocessing and tokenization
* Sequence generation
* LSTM-based deep learning model
* Next word prediction
* Accuracy ~85%

## 🛠️ Technologies Used

* Python
* TensorFlow / Keras
* NumPy, Pandas

## 📊 Model Architecture

* Embedding Layer
* LSTM Layer
* Dense Layer

## ▶️ How to Run

1. Open the notebook in Google Colab
2. Run all cells
3. Enter input text to get predictions
